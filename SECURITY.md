# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub: on the repository's
**Security** tab, choose **Advisories**, then **Report a vulnerability**. Don't
open a public issue.

Include the affected component and version, steps to reproduce, and what an
attacker could do. We'll reply in the advisory.

## Scope

This covers the streamer, the SteamVR driver, the audio driver and its setup
tool, the headset app, the account server, and the installer scripts.

Self-hosted servers are the operator's responsibility to patch and to put behind
HTTPS. Only the newest release receives security fixes.
